# Nostra-E-commerce-Website
Nostra is a responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a simple and user-friendly shopping experience with a clean design and interactive features.
Features

Responsive homepage

Collection page to browse products

Search functionality to find products

Filter functionality using JavaScript

Contact Us page

Simple and attractive user interface

Technologies Used

HTML5

CSS3

JavaScript

Pages

Home: Introduction to the website

Collections: Browse, search, and filter products

Contact Us: Contact information and form

How to Run

Download or clone this repository.

Open the project folder.

Open index.html in your browser.

Project Structure

index.html – Homepage

collection.html – Product collection page

contact.html – Contact page

style.css – Website styling

script.js – JavaScript functionality
